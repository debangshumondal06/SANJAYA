# SANJAYA

SANJAYA is a civic incident reporting and authority-management prototype. It supports pothole, garbage-overflow, and waterlogging reports, then prioritises, groups, routes, and tracks them.

# Features

Citizen reporting without login
Only Authority/admin login
Hindi, Bengali, and English enabled voice assistant for help
Issue category automatic selection with image upload option
Free-text reporting (or voice reporting) for unknown departments/issues
Voice recording enabled report submission with voice transcription
Current/incident location sharing
Unique ticket generation for each citizen report
Coordinating officer dashboard with full workflow (Redundancy/duplicate report counter, then forwarding to the appropriate department)
